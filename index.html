Part 01

三个判断，先把虚火降下来

这三条不纠正，后面每一步都会被带偏

判断一付费买量那套，你玩不起

你写在「推广」备注里的冷启动 → 增长 → 稳定三阶段、UAC、AppLovin / Unity、信息流 + CPD，是给有预算、有 LTV 模型的手游团队写的。工具类 APK 的 ARPU 接近零，信息流起投几千到几万，买来的用户既不会付费也不会留存。这一步在你这里不是「小预算测试」，是纯亏。

判断二ASO 工具不是渠道

七麦、点点、Sensor Tower、data.ai、AppTweak 这些是看数据用的，它不能给你带来一个下载。放进「发行」里会误导优先级。后五个是企业级年费产品，个人用免费版七麦或点点就够。AppGrowing 更是广告监测，和 ASO 无关。

判断三国外三方站会自己找上门

APKPure、Uptodown、Aptoide 都是爬虫抓 Google Play / GitHub 的包自动上架，你手动提交反而慢。唯一例外是 APKMirror，只收知名应用，个人新包进不去。这三个从待办里划掉，收益照拿。

Part 03

三类应用，三套打法

同样是「上架」，工具类靠商店，影视类只能靠社区和私域

工具 / 自动化类

AutoClicker 这类 · 无内容版权风险 · 商店友好

上架（按顺序做）

P0
GitHub Releases所有渠道的源头。没有它，IzzyOnDroid 和其他收录站都不会收。
P0
酷安国内安卓工具第一分发位，开发者认证免费。
P0
F-Droid开源工具标配。硬门槛：FOSS 许可证 + 不依赖 GMS / Firebase 等专有组件。
P1
IzzyOnDroidF-Droid 补充仓，接受闭源和带 GMS 的应用，只要 GitHub 有 Release。免费。
P1
华为 AppGallery国内正规商店里对个人开发者最友好的一个，实名即可注册。
P2
小米 / OPPO / vivo / 荣耀需要软件著作权证书。自办软著约 30–60 个工作日，加急另收费。
P2
Google Play工具类过审几乎无门槛，一次性注册费。只做海外增量，别当主渠道。

宣传（按转化排）

P0
酷安 · 应用动态版本更新顺手发一条，国内工具类最省力的持续曝光。
P0
V2EX「分享创造」一篇帖能吃半年搜索长尾。写清解决什么问题，别只贴下载链接。
P0
HelloGitHub 自荐中文开源圈曝光最强的一站，只收开源项目——你刚好符合。
P1
小众软件接受作者自荐，长尾流量好，适合「解决一个具体小问题」的工具。
P1
B 站30 秒演示视频比任何文案都有效，且能被长期搜索到。
P1
LINUX DO工具与 AI 类讨论热度高，发帖容忍度比 V2EX 宽松。
P2
新趣集 / Solo / 电鸭独立开发者社区，适合首发互推，量小但精准。

音频 / 媒体工具类

本地处理 · 无版权风险 · 可吃 HiFi 小众圈

上架

P0
GitHub Releases同样是一切的前提，同时存一份 SHA-256 摘要。
P0
酷安音频工具在酷安的讨论度高于普通工具，评论区常出真实需求。
P1
F-Droid + IzzyOnDroid音频处理类开源项目收录率很高，两个都提，互不冲突。
P1
Google Play媒体工具类审核最松的一档，几乎没有额外资质要求。
P2
华为 / 小米商店需软著。音频工具属「实用工具」类目，过审压力小。

宣传

P0
耳机大家坛（erji.net）国内 HiFi 圈最老最硬的池子。你导图里漏了这个，但动态范围、假 hi-res、codec transparency 这些话题只有在那儿有人接得住。
P0
B 站 HiFi / 音频区用波形、频谱、AB 对比做内容，比其他区更容易做出专业感。
P1
什么值得买音频器材类有自然流量，适合写「工具 + 器材」组合评测。
P1
Chiphell用户消费力高、爱折腾，对技术细节容忍度高。
P2
V2EX / LINUX DO / 酷安和工具类同一套打法，文案可以复用。

影视 / TVBox 聚合类

内容版权风险 · 走不了任何正规商店

先说清楚这条红线

不要往任何正规商店提交Google Play 会按版权投诉下架并可能封号；国内商店需要《信息网络传播视听节目许可证》，个人拿不到；酷安这类社区商店一旦被举报就下架，还可能连累账号。

上架

P0
GitHub Releases唯一的主分发口。TVBox 圈用户已经习惯来这里拿包。
P0
自建落地页稳定域名 + 版本列表 + 校验值。GitHub Pages 免费，但要准备备用。
P0
Telegram 频道版本推送 + 失效公告的唯一可靠通道，这个圈子的默认基建。
P1
网盘分发夸克 / 蓝奏云，解决国内直连 GitHub 慢。多备几个防失效。

宣传

P0
恩山无线论坛TVBox / 盒子类用户最集中的中文论坛。发布帖 + 持续回帖维护。
P0
TG 频道互推这个圈子的增长基本靠频道之间互相转发，找同量级频道换推。
P1
智能电视网 / ZNDS盒子用户聚集地，教程类内容容易被收录。
P1
B 站盒子测评 UP 主不用自己起号，直接寄样机或私信给做电视盒子测评的 UP 主。
P2
什么值得买 / 贴吧盒子吧、投影仪吧，长尾但稳定。
身份隔离影视类项目不要用真实身份注册开发者账号，不要接支付，不要让三个项目共用同一个 GitHub / TG 身份——一处被端会全部连坐。
Part 04

开工前先补 5 件基建，然后按这个顺序走

基建不做，后面每个渠道都要返工一次

1
版本号与包名一次定死不要一版换一个包名。渠道收录、用户升级、商店认的都是包名，改一次等于重来。
2
每个 Release 附 SHA-256你星标里的 YuqiEngine 就在这么做。工具类用户会核对，是低成本建立信任的方式。
3
应用内更新走 GitHub API不要依赖商店推送。免费、稳定，还能绕开商店审核周期。
4
一个不换的下载落地页所有宣传都指向同一个 URL。渠道会变、帖子会沉，落地页是固定入口。
5
保留旧版本下载新版出问题用户要能回滚。Release 别删，标成 Pre-release 归档即可。
第 1 周
开源三件套 + 酷安
GitHub Release 规范化（版本号、SHA-256、更新日志）→ F-Droid 提交 → IzzyOnDroid 提交 → 酷安开发者认证并上架。同时把软著材料递出去，这是唯一要等 1–2 个月的事，越早越好。
第 2–4 周
内容三连发
V2EX「分享创造」→ 隔 3 天 HelloGitHub 自荐 → 再隔 3 天小众软件投稿。B 站发一条 30 秒演示。音频类同步去耳机大家坛发实测帖。错开 3–5 天，避免同一批人重复刷到。
第 2–3 月
软著下来，补国内商店
华为先提（个人最友好），过了再提小米 → OPPO → vivo → 荣耀 → 应用宝。一次只提一个，上一个的驳回理由可以直接用来修下一个。海外 Google Play 同期开。
持续
影视类单独一条线，不共用身份
GitHub + Telegram 频道 + 恩山帖子 + 网盘，用独立账号和独立落地页。这条线不追规模，追的是「随时能断掉重来」。
裁决口径　「立刻做」= 免费、无需资质、一个人一周内能完成且能带来真实下载；「排期做」= 有明确收益但卡在资质（软著）或需要较长审核；「顺手做」= 一次性提交即可，不投入额外精力；「被动」= 平台会自动抓取，无需提交；「砍」= 已停止运营 / 流量枯竭 / 需要预算或团队 / 与你的应用形态不匹配。
关于三方小商店　91、PP 助手已停止服务；豌豆荚、UC 应用商店已并入阿里体系，独立入口流量极低；安智、历趣、优亿、华军、多特、手机之家为长尾站，个人开发者提交多无审核响应。国内安卓分发量的 90%+ 集中在华为、小米、OPPO、vivo、荣耀、应用宝六家，其余合计不足 5%——这是「砍」的依据。
平台政策提醒　各平台的开发者资质、审核类目和费用会变，提交前以官网最新要求为准。国内商店对个人开发者的资质要求在收紧，软著基本是硬门槛。
风险提示　影视聚合类应用的合规风险由发布者自行承担，本页只做渠道层面的说明，不构成合规建议。
